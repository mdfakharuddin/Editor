## 1. Project Overview

**Editor** is a browser-based design editor similar to Canva and Figma. It supports:

- Drawing and editing vector shapes (rectangles, ellipses, lines)
- Rich text editing
- Image uploads and placement
- Video clip management with an NLE-style timeline
- Keyframe animation with easing
- Clip transition effects (fade, dissolve, wipe, slide, zoom)
- Multi-page/artboard documents
- Undo/redo history
- PDF, PNG, JPG export
- Reusable text-style presets
- Drag-to-reorder layers and pages

**Technology Stack**

| Concern | Library / Version |
|---|---|
| UI Framework | React 18.3.1 |
| Build Tool | Vite 6.3.5 |
| State Management | Zustand 5.0.11 |
| Canvas Rendering | Fabric.js 5.5.2 |
| Styling | Tailwind CSS 4.1.12 + Emotion |
| UI Primitives | Radix UI (full set) |
| Icons | lucide-react 0.487.0 |
| Animation | motion 12.23.24 |
| PDF Export | jsPDF 4.2.0 |
| Drag & Drop | react-dnd 16.0.1 |
| Forms | react-hook-form 7.55.0 |

## 6. Custom Hooks

### 6.1 `useCanvas`

**File:** `src/app/hooks/useCanvas.ts`

**Signature:**
```typescript
function useCanvas(
  canvasElRef: React.RefObject<HTMLCanvasElement>,
  containerRef: React.RefObject<HTMLDivElement>
): {
  zoomIn: () => void
  zoomOut: () => void
  fitToScreen: () => void
  resetZoom: () => void
  addImage: (file: File) => void
  addShape: (type: string) => void
}
```

Initializes a Fabric.js canvas on mount, attaches all mouse/wheel event listeners, and handles the complete drawing tool lifecycle.

#### Initialization

1. Creates `new fabric.Canvas(canvasElRef.current, { ... })` with:
   - Dark background `#0d1117`
   - `preserveObjectStacking: true`
   - `fireRightClick: true`, `stopContextMenu: true`
2. Adds a white artboard `fabric.Rect` with `__isArtboard = true`, `selectable = false`
3. Attaches a `ResizeObserver` on the container div for responsive sizing
4. Calls `pushHistory()` with the initial empty canvas snapshot
5. Calls `syncInitialPageState()` from artboardStore

#### Tool Event Flow (mouse events)

| Tool | mouse:down | mouse:move | mouse:up |
|---|---|---|---|
| `select` | Default Fabric selection | — | — |
| `hand` | Start panning (`lastPanPoint`) | Pan viewport | Clear `lastPanPoint` |
| `rect` | Create preview `fabric.Rect` | Resize preview | Finalise if ≥ 5px |
| `circle` | Create preview `fabric.Ellipse` | Resize preview | Finalise if ≥ 5px |
| `line` | Create preview `fabric.Line` | Extend preview | Finalise if diagonal ≥ 5px |
| `text` | Create `fabric.IText`, enter edit mode | — | — |

For `image` tool, `addImage(file)` uses `FileReader` to load a DataURL and creates a `fabric.Image`.

#### Zoom & Pan (mouse:wheel)

- **Ctrl + Scroll:** Zoom (clamped to `ZOOM_MIN = 0.04`, `ZOOM_MAX = 24`)
- **Scroll without Ctrl:** Pan the viewport

#### Returned Helpers

| Function | Description |
|---|---|
| `zoomIn()` | Increase zoom by 10% |
| `zoomOut()` | Decrease zoom by 10% |
| `fitToScreen()` | Zoom + pan so the artboard fits the container |
| `resetZoom()` | Set zoom to 1.0 (100%) |
| `addImage(file)` | Read file, create Fabric image, center on artboard |
| `addShape(type)` | Programmatically add a shape at center |

### 6.3 `useVideoRenderer`

**File:** `src/app/hooks/useVideoRenderer.ts`

**Signature:** `function useVideoRenderer(): void`

Mounts a `requestAnimationFrame` loop that drives video playback synchronisation, keyframe animation, and transition effects. This hook is mounted once in `EditorLayout` and runs for the entire editor session.

#### Playback Loop (when `isPlaying = true`)

```
Each frame:
  1. Calculate delta time since last frame
  2. Advance playhead by delta seconds
  3. If playhead >= totalDuration → stop; loop to 0
  4. Call syncVideoPlayback(newPlayhead, isPlaying)
     → For each clip in range: set videoEl.currentTime
     → For out-of-range clips: pause videoEl
  5. applyKeyframesAtTime(canvas, newPlayhead)
  6. applyTransitionOpacity(newPlayhead)
  7. canvas.requestRenderAll()
```

#### Scrub Handler (when `isPlaying = false` and `playhead` changes)

1. For each clip: `videoEl.currentTime = playhead - clip.startTime + clip.trimStart`
2. Await all seeks (via `seeked` event or timeout)
3. `applyKeyframesAtTime(canvas, playhead)`
4. `applyTransitionOpacity(playhead)`
5. `canvas.renderAll()`

#### Helper: `applyTransitionOpacity(playhead)`

For each clip with registered transitions, calls `getTransitionOpacity(clipId, clipStart, clipEnd, playhead)` and sets `opacity` on the corresponding Fabric object.

## 14. Video & Animation System

### Video Clip Rendering Architecture

Video frames are rendered directly to the Fabric canvas with zero extra complexity:

1. Each clip has a hidden `HTMLVideoElement` (never appended to DOM)
2. A `fabric.Image` is created with the video element as its `_element`
3. On every RAF tick: `canvas.requestRenderAll()`
4. Fabric's pipeline calls `ctx.drawImage(videoEl, x, y, w, h)` to composite the current frame

### Trim Model

```
File timeline:  |----[trimStart]-------[trimEnd]----|
Canvas timeline:              |──────────|
                           startTime  startTime + (trimEnd - trimStart)
```

- `trimStart` — seconds cut from the start of the video file
- `trimEnd` — effective end position within the file (≤ `duration`)
- `startTime` — where the clip begins on the editor timeline
- Effective length = `trimEnd - trimStart`

### Playhead Synchronisation

For each clip at a given playhead time `t`:

```
if t >= clip.startTime && t < clip.startTime + (trimEnd - trimStart):
  videoEl.currentTime = t - clip.startTime + clip.trimStart
else:
  videoEl.pause()
```

### Keyframe Animation

The animation engine interpolates property values between keyframes:

```
Given keyframes at time t1 (value v1) and t2 (value v2):
  progress = (t - t1) / (t2 - t1)        ← 0.0 to 1.0
  easedProgress = easingFn(progress)
  value = v1 + (v2 - v1) * easedProgress
```

### Transition Opacity

```
Fade-in  (position: 'in'):
  if t < clipStart + transition.duration:
    opacity = (t - clipStart) / transition.duration   ← 0 → 1

Fade-out (position: 'out'):
  if t > clipEnd - transition.duration:
    opacity = (clipEnd - t) / transition.duration      ← 1 → 0

Otherwise:
  opacity = 1.0
```

## 15. Multi-Page Architecture

The editor supports unlimited pages (artboards) within a single document. A single Fabric.js canvas instance is shared across all pages.

### Page Switch Flow

```
User clicks page thumbnail
  → setActivePage(newId)
    1. saveCurrentPageState()
       - canvas.toJSON(['__id','__name','__isArtboard']) → JSON string
       - captureThumbnail() → JPEG data URL at ~15% scale
       - Store both on currentPage object

    2. loadPageOnCanvas(newPage)
       - canvas.clear()
       - canvas.loadFromJSON(newPage.fabricJSON, () => {
           canvas.renderAll()
           fitCanvasToPage(canvas, newPage)
           syncLayersFromCanvas(canvas)
         })
       - canvas.setBackgroundColor(newPage.backgroundColor)
```

### Cross-Page Object Transfer

`moveObjectsToPage(targetPageId)` works by:
1. Serializing selected objects to JSON
2. Loading target page JSON
3. Appending the serialized objects to the target page's `fabricJSON.objects` array
4. Saving the modified JSON back to the target page

## 16. History & Undo/Redo

### Stack Model

```
history = [snap0, snap1, snap2, snap3]
                                  ↑
                           historyIndex = 3  (current)
```

After `undo()`:
```
historyIndex = 2  →  canvas.loadFromJSON(history[2])
```

After `redo()`:
```
historyIndex = 3  →  canvas.loadFromJSON(history[3])
```

### Memory Management

- Maximum 50 snapshots stored
- When the limit is reached, the oldest snapshot is removed (`history.shift()`)
- Undone snapshots are discarded when a new action is performed

### Snapshot Triggers

| User Action | Trigger |
|---|---|
| Finish drawing a shape | `mouse:up` (after minimum size check) |
| Modify an object | `object:modified` event |
| Add an image | After `fabric.Image` is added |
| Layer reorder | After `canvas.moveTo()` |
| Undo/Redo itself | `isHistoryAction` flag prevents recursive push |

## 17. Export Pipeline

### PNG / JPG Export

```
1. Save: transform = canvas.viewportTransform
2. canvas.setViewportTransform([1, 0, 0, 1, 0, 0])
3. dataUrl = canvas.toDataURL({
     format: 'png' | 'jpeg',
     multiplier: scale,          // 1, 2, or 4
     quality: quality            // 0–1
   })
4. Restore: canvas.setViewportTransform(transform)
5. Trigger download: <a href={dataUrl} download="design.png">.click()
```

### PDF Export

```
1. Generate PNG at 2× scale (as above)
2. const doc = new jsPDF({
     orientation: width > height ? 'landscape' : 'portrait',
     unit: 'px',
     format: [artboardWidth, artboardHeight]
   })
3. doc.addImage(dataUrl, 'PNG', 0, 0, artboardWidth, artboardHeight)
4. doc.save('design.pdf')
```

The current implementation shows a simulated progress bar. A complete implementation requires:

1. Server-side frame extractor:
   - Seek timeline to each frame (`1/fps` steps)
   - Call `canvas.toDataURL('png')` per frame
   - Encode with FFmpeg: `ffmpeg -r {fps} -f image2pipe -i pipe:0 -b:v {bitrate} output.mp4`
